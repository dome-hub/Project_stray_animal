## Priority Issues

### [P0] เน็ตหลุดถูกแสดงผลเป็น "ไม่มีงานค้าง 🎉"

**Why it matters:** `ดึงรายงาน`, `ดึงสัตว์`, `ดึงสถิติ`, `ดึงรายงานพิกัด` (VolunteerPage.jsx:497–539) ใช้รูปแบบ `if (data) setX(data); setLoading(false)` — error ไม่เคยถูกเก็บ ไม่มี `navigator.onLine` ไม่มี error boundary ไม่มีปุ่มลองใหม่ที่ไหนเลยใน `src/` เมื่อโหลดล้มเหลว `/volunteer/reports` ตกลงไปที่ empty state ที่เป็น **ไอคอน PartyPopper** พร้อมข้อความ "ไม่มีงานที่ต้องดำเนินการในขณะนี้"

เจ้าหน้าที่ภาคสนามในกำแพงแสนทำงานบน 4G ชนบทที่สัญญาณไม่นิ่ง เปิดแอปในจุดอับ เห็นไอคอนฉลองบอกว่าเคลียร์งานหมดแล้ว แล้วเก็บโทรศัพท์ ทั้งที่มีสัตว์บาดเจ็บรออยู่ในคิว **นี่คือข้อบกพร่องเดียวในแอปที่ทำให้เกิดอันตรายทางกายภาพได้ และหน้าตาเหมือน happy path ทุกประการ**

**Fix:** เก็บ `error` ใน fetcher ทั้งสี่ลง state `โหลดผิดพลาด` แสดงสถานะล้มเหลวที่แยกออกจากกันชัดเจน (ไอคอน `WifiOff`, "โหลดรายการไม่สำเร็จ — ตรวจสอบสัญญาณอินเทอร์เน็ต", ปุ่ม "ลองใหม่" เต็มความกว้าง) และให้ PartyPopper แสดงได้เฉพาะเมื่อ request สำเร็จและได้ 0 แถวเท่านั้น

**Suggested command:** `/impeccable harden`

### [P0] URL ที่ไม่รู้จักให้หน้าขาวเปล่า ไม่มีทางออก

**Why it matters:** `src/App.jsx` ไม่มี catch-all route (`path="*"`) ยืนยันด้วยการวัดจริง: `/admin` ให้ `visibleText: 0` — หน้าขาวสนิท ส่วน `/zzz-typo-url` ให้ 38 ตัวอักษรคือแถบเมนูล่างลอยอยู่บนหน้าว่าง

`/admin` ไม่ใช่ URL สมมติ — มันคือสิ่งที่คนพิมพ์เองโดยธรรมชาติเมื่อเห็น `/admin/users` และในแอป Capacitor deep link หรือ state ที่เพี้ยนจะพาไปโผล่ตรงนี้ได้ เจ้าหน้าที่ที่เจอหน้าขาวจะสรุปว่าแอปพัง แล้วโทรหาคุณ

**Fix:** เพิ่ม `<Route path="*" element={...} />` ท้าย `<Routes>` แสดงหน้า "ไม่พบหน้านี้" พร้อมปุ่มกลับหน้าแรก และเพิ่ม `<Route path="/admin" element={<Navigate to="/admin/dashboard" />} />` (รวมถึง `/volunteer` ด้วยเหตุผลเดียวกัน)

**Suggested command:** `/impeccable harden`

### [P1] เปิดเคสด้วยคีย์บอร์ดหรือ screen reader ไม่ได้เลย

**Why it matters:** การ์ดเคสทุกใบเป็น `<div onClick>` — VolunteerPage.jsx:1067, :1384, :1873 และ TrackReport.jsx:456 ตรวจสดแล้ว accessibility tree แสดงเนื้อหาการ์ดเป็น `generic` โดยมีลิงก์ Google Maps เป็น element เดียวที่ focus ได้ ทั้ง codebase 11,300 บรรทัดมี `htmlFor` **0 ครั้ง** และ `<label>` 7 ครั้ง ช่องกรอกใน `/report` ประกาศชื่อจาก placeholder ส่วน label ที่มองเห็น "สถานที่พบ" เป็น `<p>` ที่ไม่ผูกกัน ปุ่มเลือกประเภทการแจ้งไม่มี `role="radio"` และ `aria-checked` — screen reader ไม่รู้ว่าเลือกอะไรอยู่ bottom sheet ไม่มีอันไหนมี `role="dialog"`, focus trap หรือ Escape

`<html lang="en">` บนแอปที่เป็นภาษาไทยล้วน (index.html:2) — screen reader จะอ่านภาษาไทยด้วยเสียงภาษาอังกฤษ

นี่คือบริการภาครัฐไทย เจ้าหน้าที่ที่ใช้ TalkBack หรือใครก็ตามที่ต่อคีย์บอร์ดกับแท็บเล็ตทำงานหลักของแอปไม่ได้เลย และเป็นประเด็นที่มีโอกาสสูงสุดที่จะโผล่ในการตรวจรับของราชการหลัง launch

**Fix:** เปลี่ยนการ์ดทั้งสี่แบบเป็น `<button type="button" className="w-full text-left ...">` และย้ายลิงก์ Maps ออกมาเป็น sibling (กัน interactive ซ้อนกัน) เพิ่มคู่ `id`/`htmlFor` ให้ทุก input ใน `/report`, `/login`, ฟอร์มสัตว์ ให้ตัวเลือกความเร่งด่วนและสถานะเป็น `role="radiogroup"` + `role="radio"` + `aria-checked` ทำ `<Sheet>` กลางที่มี `role="dialog" aria-modal="true"` + focus trap + Escape + ตัวจัดการปุ่ม Back ของ Android (`App.addListener('backButton')` ของ Capacitor) และแก้ `<html lang="th">`

**Suggested command:** `/impeccable audit`

### [P1] ไม่มีอะไรบอกว่าเคสค้างมานานแค่ไหน ทั้งที่สัญญากับประชาชนไว้ 24 ชั่วโมง

**Why it matters:** ตอนส่งรายงาน ระบบเขียน notification ว่า "เจ้าหน้าที่จะดำเนินการภายใน 24 ชั่วโมง" (ReportAnimal.jsx:450) แต่ไม่มีอะไรในหน้าเจ้าหน้าที่แสดงนาฬิกาเรือนนั้น ตัวเลือกเรียงมีแค่ "ล่าสุด" กับ "ความเร่งด่วน" อายุเคสโผล่แค่เป็น `text-xs text-gray-400`

บนระบบจริงตอนนี้ เคสเดียวที่เปิดอยู่คือ `#000034` รับเรื่องตั้งแต่ **21 ก.ค.** และยังอยู่ที่ `รับเรื่องแล้ว` มา 12 วัน — หน้าตาเหมือนเคสที่เพิ่งรับเมื่อเช้าทุกประการ

ผลิตภัณฑ์ให้สัญญา SLA แทนหน่วยงาน แล้วไม่ให้เครื่องมือรักษาสัญญานั้น เครื่องมือ dispatch ที่ตอบไม่ได้ว่า "อะไรเลยกำหนด" ไม่ใช่เครื่องมือ dispatch

**Fix:** คำนวณชั่วโมงจาก `created_at` (เคสรอ) หรือ `updated_at` (เคสกำลังทำ) แสดง chip อายุมุมขวาบนการ์ด — กลางเมื่อ < 24 ชม., เหลืองอำพัน 24–72 ชม., แดงเกินนั้น พร้อมข้อความ "เกินกำหนด 3 วัน" เพิ่ม "ค้างนานที่สุด" เป็นตัวเลือกเรียงที่สาม และตั้งเป็นค่าเริ่มต้นของ `/volunteer/update` แสดงจำนวนเคสเลยกำหนดในหัวข้อ

**Suggested command:** `/impeccable shape`

### [P1] Error คือ `alert()` 29 จุดที่โยนข้อความฐานข้อมูลภาษาอังกฤษดิบใส่หน้าเจ้าหน้าที่

**Why it matters:** `alert('บันทึกไม่สำเร็จ: ' + error.message)` และพี่น้องอีก 28 จุดกระจายทั่ว AdminPage, ProfilePage, ReportAnimal, TrackReport, VolunteerPage โดย `error.message` คือสตริงจาก Supabase/PostgREST — ภาษาอังกฤษ มักมีชื่อ constraint หรือ RLS policy ปนมา ซ้ำเติมด้วย `/login` ไม่มีลิงก์ลืมรหัสผ่านเลย และแสดง "Invalid login credentials" ตรง ๆ

ในบิลด์ Capacitor สิ่งเหล่านี้จะขึ้นเป็น system dialog ที่มีชื่อ origin ของแอปเป็นหัวเรื่อง — ซึ่งคือลายเซ็นทางสายตาของ "แอปพัง" พอดี แสดงต่อเจ้าหน้าที่ราชการที่อ่านข้อความนั้นไม่ออกและไม่มีทางกู้คืน เจ้าหน้าที่ที่ลืมรหัสผ่านหลังใช้ไปหนึ่งเดือนจะไม่มีทางกลับเข้าเครื่องมือทำงานของตัวเอง

**Fix:** แทน `alert()` ทุกจุดด้วย `toast()` ที่มีอยู่แล้ว (VolunteerPage.jsx:659) โดยแม็ปข้อความไทยจาก error code และ log สตริงดิบไว้ที่ console เท่านั้น เพิ่ม "ลืมรหัสผ่าน?" ใต้ปุ่มเข้าสู่ระบบต่อกับ `supabase.auth.resetPasswordForEmail` และเปลี่ยน "Supabase กำลังตื่นจาก sleep" เป็น "กำลังเชื่อมต่อระบบ อาจใช้เวลาสักครู่"

### [P2] บันทึกการตายเป็นการกดครั้งเดียวในรายการ 7 ตัวเลือก และ contrast ต่ำทั้งแอป

**Why it matters (ก):** เคสบาดเจ็บที่ขั้น "ลงพื้นที่แล้ว" จะเห็น 2 ตัวเลือกความคืบหน้า + 4 ตัวเลือกปิดเคส + ปุ่มรวมเคส = **7 ตัวเลือกแบน ๆ** โดย `เสียชีวิต` มีสไตล์เหมือน `ส่งคืนเจ้าของสำเร็จ` ทุกประการ เลือกแล้วกดบันทึกจะเขียนสถานะและส่ง notification แจ้งข่าวการตายถึงประชาชนทันที ไม่มีการยืนยัน ไม่มี undo — `confirm()` เพียงจุดเดียวในทั้ง codebase ใช้กับการอัปโหลดรูปที่ล้มเหลว

**Why it matters (ข):** วัดสดที่ 375px — ป้ายเมนูล่างทุกอันคือ 10px ที่ **2.54:1**, เลขที่รายงานบนการ์ด 12px ที่ **2.54:1**, ป้ายรางวัลใน banner **9px ที่ 2.02:1** และที่หนักที่สุด: **ปุ่มส่งรายงานหลักใน `/report` คือ ขาวบนส้ม `#f97316` = 2.8:1** ปุ่มที่สำคัญที่สุดในแอปตกมาตรฐาน ขนาดปุ่ม: toggle เรียงลำดับ 51×24px, ปุ่ม "ออก" 25×20px, ลูกศร banner **10×20px**

เจ้าหน้าที่ใช้มือเดียวกลางแดดกำแพงแสน ซึ่ง contrast ที่ใช้งานได้จริงจะต่ำกว่าค่าที่วัดในห้องมาก ลูกศรกว้าง 10px กดด้วยนิ้วโป้งไม่ได้ และเลขที่รายงาน — สตริงที่เจ้าหน้าที่ต้องอ่านให้ประชาชนฟังทางโทรศัพท์ — เป็นข้อความที่ contrast ต่ำที่สุดบนการ์ด ขณะที่การกระทำที่หนักที่สุดในผลิตภัณฑ์มีแรงเสียดทานน้อยกว่าการกดออกจากระบบ

**Fix:** แยกกลุ่ม "ปิดเคส" ออกมาให้ต่างทางสายตา และ gate ทุกสถานะปลายทางด้วย sheet ยืนยันที่ระบุผลลัพธ์ ("ปิดเคส #000034 เป็น 'เสียชีวิต' — ผู้แจ้งจะได้รับการแจ้งเตือน และย้อนกลับไม่ได้") ยกพื้น: ข้อความเนื้อหาขั้นต่ำ 12px, ใช้ `text-gray-500` (4.83:1) แทน `text-gray-400` สำหรับข้อความที่มีความหมาย, สงวน `text-gray-400` ไว้สำหรับของประดับล้วน, บังคับพื้นที่กด 44×44 ขั้นต่ำด้วย padding และแก้สีปุ่มส่งรายงานให้ผ่าน 4.5:1

**Suggested command:** `/impeccable polish`

## Persona Red Flags

**Casey (ผู้ใช้มือถือที่ถูกขัดจังหวะ)** — persona หลักของงานนี้ ทุก P0/P1 ตกใส่เธอหมด
- เปิด `/volunteer/reports` ที่สี่แยกด้วยสัญญาณขีดเดียว เห็นสถานะ PartyPopper "ไม่มีงาน" เธอเข้าใจผิดและไม่มีทางรู้
- เอานิ้วโป้งจิ้ม "ความเร่งด่วน" ที่เป็นเป้า 87×24px วางห่างจากการ์ดเต็มความกว้างแค่ 8px แล้วเปิด sheet เคสแทน
- อ่าน "รอระบุสายพันธุ์" บนการ์ด inbox เปิดเคสเดียวกันใน `/volunteer/update` แล้วเห็น "**ไม่สามารถวิเคราะห์ได้**" เป็นชื่อสัตว์ — การ์ดอัปเดต (VolunteerPage.jsx:1395) เป็นที่เดียวที่ลืมใส่ guard `แสดงสายพันธุ์สัตว์` ที่ใช้ทุกที่ ยืนยันสดบนเคส `#000034`

**Sam (screen reader / คีย์บอร์ด)** — ใช้ผลิตภัณฑ์ไม่ได้เลย
- เปิดเคสไม่ได้สักเคส การ์ดทั้งสี่แบบเป็น `div onClick` ไม่มี role, tabindex, key handler
- ใน `/report` ช่องสถานที่ประกาศเป็น placeholder ส่วน label "สถานที่พบ" และเครื่องหมาย `*` ไม่ผูกกัน
- ไม่รู้ว่าเลือก สัตว์ดุร้าย / บาดเจ็บ / พลัดหลง อันไหนอยู่ — สามปุ่มเปล่าไม่มี `aria-checked`
- focus ไม่เคยถูกย้ายเข้า sheet และไม่เคยถูกขัง หลัง sheet เปิด Tab ยังเดินผ่าน chip กรองและปุ่มเมนูล่าง 5 ปุ่มที่อยู่ข้างใต้

**Riley (คนทดสอบขอบ)** — เจอรอยต่อของ state machine
- แจ้งหมาบาดเจ็บ เจ้าหน้าที่ย้ายเป็น `อยู่ศูนย์พักพิง` → `/track` แสดงขั้น 3 จาก 4 พร้อม "รักษาตัว" ที่ไม่มีวันถูกเติมตลอดกาล ขณะที่ฝั่งเจ้าหน้าที่เคสหายจากคิวไปแล้ว สองไฟล์เห็นไม่ตรงกันว่า "ปิดเคส" แปลว่าอะไร (VolunteerPage.jsx:160 vs TrackReport.jsx:116–120)
- กดอ่าน notification บนเครื่องหนึ่ง สถานะอ่านแล้วเก็บใน `localStorage` (`noti_read_${user.id}`) สำหรับ role volunteer/admin → เลข badge เป็นของเฉพาะเครื่องและรีเซ็ตเมื่อลงแอป Capacitor ใหม่
- เปิดโหมดเครื่องบินกลางคัน `ส่งรายงาน` → `alert()` ภาษาอังกฤษ ไม่ทิ้งอะไรไว้และไม่อธิบายอะไรเลย

## Minor Observations

- `/admin/settings` คือ 5 แถวอ่านอย่างเดียว (เลขเวอร์ชัน, "Supabase (PostgreSQL)") แต่กินช่อง 1 ใน 5 ของเมนูหลักแอดมิน — เป็นสเปคชีตที่ใส่ป้ายว่าตั้งค่า
- `exportCSV` เขียนหัวคอลัมน์เป็น `Object.keys(data[0])` → เจ้าหน้าที่ได้ไฟล์ที่มีหัวคอลัมน์ `created_at`, `reporter_id`, `publish_mode` สำหรับเอาไปทำรายงานราชการภาษาไทย และการ export `users` ส่งออกทุกคอลัมน์ของทุกบัญชีในคลิกเดียว ไม่มียืนยัน ไม่มีให้เลือกคอลัมน์ — ควรดูเรื่อง PDPA ก่อน launch
- หัวข้อกลุ่มวันที่ใช้ไอคอน lucide `<Calendar>` ในหน้าเจ้าหน้าที่ แต่ใช้ emoji 📅 ใน `/track` — เป็น emoji ตัวเดียวในแอปที่ใช้เป็นส่วนประกอบ UI
- `/volunteer/map` เขียนว่า "แตะสองครั้งเพื่อจัดการ" — double-tap บนอุปกรณ์สัมผัสคือท่าซูมของเบราว์เซอร์ ทั้งค้นพบยากและไม่น่าเชื่อถือ
- ขั้นสุดท้ายของ `ProgressBar` เปลี่ยนป้ายเป็นสตริงสถานะดิบในคอลัมน์กว้าง 52px สูง 10px — "ส่งคืนเจ้าของสำเร็จ" ใส่ไม่ลง
- การ์ดผล AI แสดง "ความแม่นยำ 0%" เป็นแถวหน้าตาปกติเมื่อวิเคราะห์ล้มเหลว ข้าง ๆ "ไม่สามารถวิเคราะห์ได้" — นำเสนอความล้มเหลวด้วยภาษาภาพของผลลัพธ์
- ไม่มี `autoComplete` บน input ของ login/register — password manager บนมือถือจะไม่เสนอกรอกหรือบันทึกให้ ซึ่งเพิ่มโอกาสที่จะต้องใช้ทางลืมรหัสผ่านที่ยังไม่มี
- ชื่อแอปมี 4 แบบในระบบเดียว: "JaengJon" / "แจ้งจร" / "ระบบจัดการสัตว์จร" / `appName` ใน config

## Questions to Consider

1. State machine ของคุณรู้ว่าสัตว์บาดเจ็บต้องผ่านศูนย์พักพิงก่อนถึงจะรับเลี้ยงได้ แล้วทำไม *อินเทอร์เฟซ* ถึงไม่รู้ว่าเคสที่ค้างที่ `รับเรื่องแล้ว` มา 12 วัน เป็นคนละวัตถุกับเคสที่เพิ่งรับเมื่อเช้า — ในเมื่อคุณสัญญากับประชาชนไว้ 24 ชั่วโมง
2. คุณสร้าง geo-query รัศมี 100 เมตรเพื่อกันเพื่อนบ้านสองคนแจ้งหมาตัวเดียวกันซ้ำ งบความใส่ใจเทียบเท่าสำหรับเจ้าหน้าที่ที่ต้องบันทึกว่าหมาตัวนั้นตายแล้วอยู่ที่ไหน
3. `อยู่ศูนย์พักพิง` แปลว่า "จบแล้ว" สำหรับเจ้าหน้าที่ แต่แปลว่า "ยังดำเนินการอยู่" สำหรับคนที่แจ้ง อันไหนพูดความจริง — และ progress bar ที่ค้างของประชาชนกำลังสอนอะไรเขาเรื่องว่าแอปนี้ควรค่าแก่การเปิดอีกครั้งไหม
4. Empty state เป็นไอคอนฉลอง คุณตัดสินใจว่ามันแปลว่าอะไรเมื่อรายการว่าง — และมีใครเขียนไว้ไหมว่ากรณีที่รายการว่างเพราะเน็ตล่มควรเป็นยังไง
5. ทุกหน้าจอเป็นคอลัมน์กว้างเท่ามือถือที่มีป้ายเมนู 10px อ่านกลางแดดนครปฐม type scale นั้นถูกเลือกเพื่อเจ้าหน้าที่ที่ยืนอยู่กลางทุ่ง หรือเพื่อ mock บนจอเดสก์ท็อปที่สว่าง
